## About

Sprintly is a full-stack web application presented here through one convenient project page. The frontend and backend live in separate repositories; use the links above to explore each codebase or open the deployed app.

The frontend repository includes pages for login, dashboard, projects, project details, and settings. This README describes the visible application areas and verified implementation stack without assuming additional product behavior.

## Repositories

## Local development

The two codebases are maintained independently. Follow the setup instructions in each repository for prerequisites, configuration, and local run commands:

- [Frontend setup and source](https://github.com/swapnil12042002/sprintly-frontend)
- [Backend setup and source](https://github.com/swapnil12042002/sprintly-backend)

The backend requires environment-specific database and security configuration. Configure secrets and connection details locally; do not commit credentials.

## Deployment

The live frontend is hosted at [sprintly-frontend-eight.vercel.app](https://sprintly-frontend-eight.vercel.app/login). For the latest deployment configuration and backend hosting details, see the source repositories. Deployment providers and runtime settings can change independently of this showcase page.
